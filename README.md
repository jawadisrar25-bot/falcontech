# Falcon Tech OHSS — Pastel Glass Front-End

Open `index.html` in a modern desktop browser. No setup or server is required.

The application contains 250 named routes across 19 OHSS sections, retaining local-storage record handling, record forms, search, filtering, status changes, charts, calendars, risk matrices, exports and navigation from the previous release.

The new appearance is inspired by the supplied reference image: pastel lavender/mint/sky gradients, semi-transparent panels, rounded surfaces, soft borders and restrained typography. All visible branding uses Falcon Tech.

This is a browser-only front-end. Data in it is illustrative and locally stored; it is not a production database, medical record system, or live enterprise integration.
